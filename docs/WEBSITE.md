## 🔜 SUSUNOD NA GAGAWIN

### HAKBANG 1 — Makabuo ng APK ang Workflow
- ✅ Ayusin ang `build.yml` → TALAGANG BUBUO NG `.apk` FILE
- ✅ I-save ang nabuong APK bilang **Artifact** → Lumabas sa Actions Page

### HAKBANG 2 — Magkaroon ng Download Link sa Website
- ✅ Kapag may APK Artifact na → Maglalagay ng **direktang link sa website**
- ✅ Pindutin ang link → **AGAD MADA-DOWNLOAD ANG APK/ZIP!**
- ✅ Habang wala pa — Ipakita muna: **"Handa na malapit — Hinihintay ang unang APK!"**
